# 《风息村落物语》(Windbreath Village) 游戏设计文档

## 1. 核心定位与体验
- **平台**：Android 竖屏单手休闲手游（兼容 Windows 桌面键鼠）。
- **设计原则**：零失败压力、随时中断自动续玩、通过「邻接生态协同 + 道路物流 + 居民解锁」让传统六边形拼图真正运转呼吸。

## 2. 六边形生态与邻接协同规则
采用 **Flat-top（平顶）轴向坐标 `(q, r)`**，每块地块拥有 6 条固定拓扑边（`grass` / `river` / `road`），顺时针旋转 `60° × rot` 即可对齐拼接：

| 协同机制 | 触发条件 | 实际效果 |
| :--- | :--- | :--- |
| **溪流灌溉 ×2** | 麦田 / 茶园 邻接任意水系（直溪、弯溪、荷塘、水车、木桥、温泉） | 农田产量翻倍，和煦度额外 +3，计入「灌溉农田」目标 |
| **水力丰收 ×2** | 农田 邻接 【水车磨坊】 | 农田产量翻倍，和煦度额外 +3 |
| **宜居风景宅 +4** | 青瓦民居 / 灯笼茶寮 邻接 花海、竹林、荷塘、风铃塔或温泉亭 | 和煦度额外 +4，吸引「打盹橘猫·团子」入住 |
| **水系 / 石路连通** | 相邻两格同为 `river` 或同为 `road` 且对齐 | 溪水/石板路自然汇合，分别加 +3 / +2 和煦，并构成居民行走路径 |
| **跨溪通途 +6** | 【灯笼木桥】同时连通水路与石路 | 桥上通人行、桥下通溪水，瞬间贯通两岸村落 |
| **风铃和鸣 +3** | 任意地块邻接 【风铃花塔】 | 周围一圈全部地块享额外 +3 和煦 |

## 3. 5 座风物建筑与消耗
- **水车磨坊**：消耗 `稻穗 8 · 竹木 4`，提升附近农田产出并产出稻穗。
- **灯笼茶寮**：消耗 `茶香 8 · 竹木 5`，服务连通石路上的村民并产出佳茗。
- **灯笼木桥**：消耗 `竹木 6 · 稻穗 4`，四向同时承载水系与道路。
- **风铃花塔**：消耗 `茶香 6 · 稻穗 6`，大幅提高周围一圈村落和煦度。
- **云泉温泉亭**：消耗 `茶香 10 · 竹木 8`，竹影水雾间吸引稀有雪顶小狐。

## 4. 四种昼夜氛围与白噪音伴侣
支持随时切换 **晨曦薄雾 / 午后暖阳 / 落日余晖 / 萤火夏夜**，搭配独立调节的 **温暖原声室内乐配乐 + 浅溪竹叶风声 + 林间细雨白噪音**，配合右上角「赏景」纯净无 UI 模式，可作为随身桌面疗愈伴侣。
